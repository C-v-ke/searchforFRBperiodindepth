# A Second-scale Periodicity in an Active Repeating Fast Radio Burst Source

This repository contains the source code and data used to generate all figures for the manuscript *A second-scale periodicity in an active repeating fast radio burst source*.

The repository includes the burst catalogues analyzed in the study, processed data products, periodograms, folded phases, simulation outputs, and the Python code used for the periodicity and significance analyses.

## Quick start

The analysis was developed with Python 3.12.7. Install the Python dependencies with:

```bash
python -m pip install -r requirements.txt
```

Run the scripts and notebooks from the repository root so that the relative data paths resolve correctly. Computationally intensive results used in the manuscript are already included in the corresponding results directories.

## Figure-generation notebooks

- Main Figures 1–10: [`Plotting_Figures.ipynb`](Plotting_Figures.ipynb)
- Supplementary Figures 1–9: [`Plotting_Supplementary_Figures.ipynb`](Plotting_Supplementary_Figures.ipynb)

## Analysis and simulation scripts

- `Phase_folding_analysis.py` implements the phase-folding and period-search analysis.
- `Significance_analysis.py` generates the simulations used for Main Figures 8–10. Full-scale settings are documented next to the reduced example settings in the script.
- `Multiple_emission_sites.py` generates the simulations used for Supplementary Figure 9.
- `Comparison_analysis.py` generates the simulations used for Supplementary Figures 5 and 7.
- `Extracting_fits_start_end.py` extracts start and end times from PSRFITS files.

## Repository structure

- `Data/` contains the burst tables, processed pulse-profile arrays, observing-session windows, the pulsar-catalogue snapshot, and other analysis inputs.
- `Periodograms/` contains the period-search results for all observing days.
- `Folded_phases/` contains the folded-phase distributions for all observing days.
- `Significance_results/` contains the bootstrap and simulation products used in the significance analysis.
- `Comparison_results/` contains the simulation products used for comparison with other analysis choices.
- `FITS_start_end/` contains the start and end times extracted from the FAST follow-up PSRFITS files.

## Reproducibility notes

The plotting notebooks load the precomputed products included in this repository. Several full-scale simulations use up to $10^9$ trials and therefore require substantially more computation than the reduced examples provided in the scripts. Random seeds and the full-scale parameter values are recorded in the scripts and in the filenames or metadata of the archived outputs.
